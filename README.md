This was a very simple project, It contains 1 new node which should make it easier to work with sprite stacking, I might update this project later, but I'm not sure...


to use this just download the zip titles "sprite_stacker V02.zip", uncompress it, then in your godot project make an addons folder, place the unzipped files in the addon folder.
after you've done that in your project settings, under the plugins tab, enable sprite stacker by badNam3
